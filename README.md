# Espace Nouvel Air — Site de Gaël Aymon

Site vitrine pour Gaël Aymon (magnétisme, massage métamorphique, soins traditionnels), à Leytron, Valais.

🔗 **Site en ligne :** *(à ajouter une fois Pages activé — format `https://167korn-create.github.io/NOM-DU-REPO/`)*

## Contenu

Site en plusieurs petits fichiers (plus léger et plus fiable à télécharger qu'un seul gros fichier) :
- `index.html` — la page (HTML/CSS/JS, ~19 Ko)
- `gael.jpg`, `cabinet.jpg` — les deux photos
- `logo-header.webp`, `logo-hero.webp` — le papillon (petite + grande taille)
- `og-image.jpg` — image affichée quand le lien est partagé sur WhatsApp/Messenger/iMessage

Les 6 fichiers doivent rester ensemble, à la racine du repo, avec ces noms exacts.

Sections : Accueil · Gaël · Prestations · Le Cabinet · Contact

⚠️ WhatsApp met l'aperçu en cache après un premier partage. Si le lien a déjà été envoyé une fois sans image, renvoyer exactement la même URL peut encore montrer l'ancien aperçu pendant plusieurs jours. Pour forcer un aperçu à jour tout de suite : ajouter `?v=2` à la fin de l'adresse au moment de l'envoyer (ex. `.../espace-nouvelair-site/?v=2`).
